indexação e voltar para a Home, os cards de estatísticas continuam
mostrando valores desatualizados. Causa: useFaceSearch.startIndexing
só chama getStoredIndexStats quando result.status === 'completed'.
Quando o status é 'cancelled', as fotos JÁ foram salvas em SQLite por
cada saveIndexedPhoto, mas a UI não relê.

- artifacts/busca-facial-local/hooks/useFaceSearch.ts

Nenhum outro arquivo deve ser alterado.

    if (result.status === 'completed') {

      if (mountedRef.current) {

      }
    }
    if (mountedRef.current) {
      setStatus(result.status === 'completed' ? 'ready' : 'cancelled');
    }
    return result;
  } catch (caught) {
    // bloco existente, não alterar
  } finally {
    // bloco existente, não alterar
  }

Substituir APENAS o conteúdo do try (mantendo catch e finally como
estão) por:
