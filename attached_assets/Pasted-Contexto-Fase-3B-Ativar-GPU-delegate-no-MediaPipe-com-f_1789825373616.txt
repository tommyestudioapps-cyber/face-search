Contexto: Fase 3B. Ativar GPU delegate no MediaPipe com fallback
automático para CPU. A Fase 3A já adicionou timeout com withTimeout,
e o diagnóstico confirmou:
- Delegate.CPU = 0, Delegate.GPU = 1 (enum do pacote, confirmado
  em TS, Kotlin e Swift).
- O código Kotlin do pacote tem comentário explícito de que GPU
  precisa rodar na thread que inicializou o módulo — daí a
  necessidade de fallback.
- O arquivo usa require() dinâmico para o módulo nativo, de propósito.
  Portanto NÃO vamos importar Delegate do pacote (isso forçaria
  carregamento em import-time). Vamos usar const local.

Esta etapa toca UM arquivo:
- artifacts/busca-facial-local/services/faceCapture/nativeAdapter.ts

Nenhum outro arquivo deve ser alterado.

Passo 1 — Adicionar const local Delegate e classe de timeout

Logo após os imports e antes da interface NativeMediaPipeRuntime,
adicionar:

  const Delegate = {
    CPU: 0,
    GPU: 1,
  } as const;

  type DelegateValue = (typeof Delegate)[keyof typeof Delegate];

  class DetectionTimeoutError extends FaceCaptureError {
    constructor() {
      super(
        'processing-failed',
        'A detecção facial demorou demais para responder.',
      );
    }
  }

Nota: a classe DetectionTimeoutError existe só para permitir que o
fallback diferencie "GPU falhou rápido" de "GPU travou e o timeout
disparou". Não renomeia FaceCaptureError.

Passo 2 — Atualizar o tipo da interface

Na interface NativeMediaPipeRuntime, trocar:
  delegate: number;
por:
  delegate: DelegateValue;

Passo 3 — Trocar o onTimeout do withTimeout para usar a classe nova

No withTimeout chamado dentro de detectFacesWithMediaPipe, onde hoje
está:
  () =>
    new FaceCaptureError(
      'processing-failed',
      'A detecção facial demorou demais para responder.',
    ),
substituir por:
  () => new DetectionTimeoutError(),

Passo 4 — Extrair helper detectWithDelegate

Antes de detectFacesWithMediaPipe, adicionar função interna:

  async function detectWithDelegate(
    runtime: NativeMediaPipeRuntime,
    imagePath: string,
    delegate: DelegateValue,
  ): Promise<NativeResultBundle> {
    return withTimeout(
      runtime.faceLandmarkDetectionOnImage(
        imagePath,
        faceCapture.modelAssetName,
        {
          numFaces: faceCapture.maxFaces,
          minFaceDetectionConfidence: faceCapture.minDetectionConfidence,
          minFacePresenceConfidence: faceCapture.minPresenceConfidence,
          minTrackingConfidence: faceCapture.minTrackingConfidence,
          delegate,
        },
      ),
      NATIVE_DETECTION_TIMEOUT_MS,
      () => new DetectionTimeoutError(),
    );
  }

Passo 5 — Reescrever o corpo de detectFacesWithMediaPipe

Substituir o bloco try/catch atual por:

  try {
    let result: NativeResultBundle;
    try {
      result = await detectWithDelegate(runtime, imagePath, Delegate.GPU);
    } catch (gpuError) {
      if (gpuError instanceof DetectionTimeoutError) {
        // O nativo ainda pode estar rodando em background; não
        // disparamos uma segunda detecção só para cair em CPU.
        throw gpuError;
      }
      if (__DEV__) {
        console.log('[FaceCapture] GPU delegate falhou, usando CPU', {
          error:
            gpuError instanceof Error ? gpuError.message : String(gpuError),
        });
      }
      result = await detectWithDelegate(runtime, imagePath, Delegate.CPU);
    }
    return mapNativeResult(result);
  } catch (error) {
    if (error instanceof FaceCaptureError) {
      throw error;
    }
    throw mapNativeError(error);
  }

Regras:
