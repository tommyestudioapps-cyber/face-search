Crie um aplicativo mobile moderno utilizando React Native com Expo (TypeScript) e Tailwind CSS (NativeWind). O app deve ter visual profissional de startup de tecnologia séria, utilizando um Dark Mode elegante e minimalista (tons de cinza escuro #0F172A, preto, e destaques em azul/violeta elétrico como #6366F1).

O aplicativo tem como objetivo realizar reconhecimento e busca facial 100% no dispositivo (local), sem custos de servidores externos.

### 1. ONBOARDING E PERMISSÕES
- Tela inicial amigável e profissional explicando a privacidade: "Suas fotos são processadas 100% no seu dispositivo e nunca saem do seu celular".
- Solicitador claro de permissão de acesso à Galeria de Fotos do Android/iOS.

### 2. ARQUITETURA E FLUXO PRINCIPAL
- Tela Principal:
  - Botão para carregar ou tirar uma foto.
  - Ferramenta de enquadramento/crop para que o usuário isolamento apenas a cabeça/rosto da pessoa desejada.
  - Botão "Buscar este Rosto na Galeria".
- Processamento Local:
  - Configure a estrutura para detecção facial e extração de embeddings (utilize bibliotecas como @vladmandic/face-api, react-native-fast-tflite ou estruturas compatíveis com Expo para processamento local de imagens).
  - Crie um serviço local usando SQLite (expo-sqlite) para salvar o vetor numérico (embedding) das fotos processadas + o caminho local da imagem, evitando reprocessar a galeria toda vez.
  - Algoritmo de comparação local (distância euclidiana/cosseno) para comparar o rosto selecionado com os vetores salvos no SQLite.
- Tela de Resultados:
  - Grid moderno exibindo todas as fotos encontradas no celular onde o rosto aparece.
  - Indicador de porcentagem de similaridade/confiança.

### 3. MONETIZAÇÃO E ESPAÇOS NA UI
- Espaço dedicado (placeholder estilizado) no rodapé da tela principal para Anúncio em Banner (AdMob Banner).
- Trava de Conexão com Internet: Antes de disparar a busca pesada na galeria, o app deve checar se o dispositivo tem internet (NetInfo). Se estiver offline, exiba um modal amigável solicitando conexão para liberar o recurso gratuito.
- Lógica/Modal para Anúncio de Recompensa (Rewarded Ad): Antes de revelar os resultados da busca, exiba uma tela/modal simulando o carregamento de um vídeo de recompensa.

### 4. UI/UX (ESTILO STARTUP SÉRIA)
- Design Dark Mode limpo, com cards levemente elevados e bordas suaves.
- Feedback visual durante todo o processo (Spinners de carregamento elegantes, barras de progresso ao analisar a galeria).
- Tipografia moderna, botões com estados de clique nítidos e ícones minimalistas (Lucide React Native / Feather Icons).
